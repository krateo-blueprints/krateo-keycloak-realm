# API

All kinds are generated by keycloak-config-kog in `resourceGroup` (resources `v1`, Configurations
`v1alpha1`).

| kind | name | annotations |
|---|---|---|
| `KeycloakRealmConfiguration`, `KeycloakGroupConfiguration`, `KeycloakClientConfiguration`, `KeycloakUserProfileConfiguration`, `KeycloakServiceAccountRoleMappingConfiguration` (with `identityLifecycle`) | `configuration.name` | `helm.sh/resource-policy: keep` |
| `KeycloakRealm` | `<realm>` | `krateo.io/deletion-policy` |
| `KeycloakGroup` | `<realm>-<group>` | `krateo.io/deletion-policy` |
| `KeycloakClient` | `<realm>-<clientId>` | `krateo.io/deletion-policy` |
| `KeycloakServiceAccountRoleMapping` (with `identityLifecycle`) | `<realm>-<clientId>-roles` | `krateo.io/deletion-policy` |
| `OIDCConfig` (`oidc.authn.krateo.io/v1alpha1`, only where that API exists) | `oidcConfig.name` | none |

The client is public, authorization code with PKCE S256 only, and carries an inline
`oidc-group-membership-mapper` with `full.path: "false"`, so the `groups` claim holds bare names
(`tenants`, not `/tenants`). That value is fixed in the template.
